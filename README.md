# 无名杀 · 无尽模式与 DIY 武将改版

> **非官方、个人学习与游玩用途的二次开发项目**。本仓库基于开源项目 [《无名杀》（libccy/noname）](https://github.com/libccy/noname) 进行修改，重点是 **单人无尽闯关、武将养成、DIY 武将技能与运行稳定性**。这不是《三国杀》或《无名杀》官方发布的版本，也不代表上游开发团队。

**本仓库：** [hongmoxian/sanguo-kill2](https://github.com/hongmoxian/sanguo-kill2)

**上游项目：** [libccy/noname](https://github.com/libccy/noname)

## 本分支主要做了什么？

以下是本分支相对所使用的上游代码所做的主要改动；基础游戏引擎、绝大多数既有武将、卡牌、界面与素材均来自原项目及其生态，**不属于本分支的原创成果**。

### 1. 独立的单人「无尽模式」

- 在游戏模式选择界面提供独立的 **无尽模式** 入口，底层复用现有对决模式的战局引擎。
- 新游戏从 **无尽 3-1（1v3）** 开始；大关推进后敌人数量递增，最多 **1v7**。
- 新游戏可从候选池**自由选择 3 名武将**：1 名主将、2 名备用武将；支持大关时切换备用武将，以及主将阵亡后接替。
- 提供最多 **3 次开局换手牌**；进入新大关时提供奖励选择（体力上限与回复、摸牌、护甲、额外出【杀】次数）。
- 记录关卡、已通关数、部分角色状态及备用武将等信息，支持在重新进入无尽模式时选择继续或开始新游戏。

> **存档限制：** 目前主要保存关卡进度和部分角色数据，并非完整的「任意时刻战局快照」；不能据此保证手牌、当前回合和所有临时技能状态原样恢复。存档保存在浏览器本地环境，清理网站数据或更换浏览器可能导致进度丢失。

### 2. DIY 张春华：技能组合与成长机制

在 `character/diy/` 中配置了可在无尽模式选择的 `diy_zhangchunhua`（初始体力上限 **8**），共登记 **19 项技能**。

其中重点定制、调整的玩法包括：

- **〖割圆〗**：用实际进入弃牌堆的牌点亮点数圆环；完成后移除两端点数、重建圆环。
- **〖解术〗**：围绕圆环状态提供手牌上限与摸牌等联动。
- **〖股算〗**：与圆环缩减进程关联的觉醒机制。
- **〖杀意〗、〖镇魂〗等**：按照本地玩法调整攻击、弃牌与封印效果。

其余技能中有复用、继承或调整自既有武将技能的部分，例如〖国色〗、〖固政〗、〖惴恐〗等；**19 项技能不代表 19 个均为原创设计**。

### 3. 无尽模式流程和兼容性修复

针对实际游玩和浏览器测试，修复或调整过：

- 无尽模式启动、选将事件排队与技能注册；
- 页面更新后旧 Service Worker / 缓存造成的脚本版本不一致；
- 敌方武将池、换将与部分存档恢复逻辑；
- 部分 DIY 技能触发顺序与游戏事件兼容问题；
- 〖割圆〗结算时未定义变量 `litAny` 导致的运行时错误，以及重复触发防护。

这些改动以可用性为目标，但并不意味着所有技能交互、所有存档场景均已完整验证。

## 如何在本地运行

推荐使用较新的 **Google Chrome / Chromium**，通过本地 HTTP 服务打开游戏，不建议直接双击 `index.html` 使用 `file://` 协议。

需要提前安装 [Deno](https://deno.com/)。

在项目根目录执行：

```powershell
cd E:\sanguo-kill
deno task start
```

随后在 Chrome 打开：

**http://localhost:8089/index.html?mode=endless**

首次启动时按页面提示完成初始化及开源协议确认。进入「无尽模式」后，可以选择 DIY 张春华作为主将。

> 如果你将项目克隆到其他位置，请把上面的 `E:\sanguo-kill` 替换成实际目录。服务器默认使用 8089 端口；本地需允许该端口访问。

## 测试与验证

本仓库提供了针对 DIY 张春华的可重复执行测试：

```powershell
node tests/diy_zhangchunhua.skill.test.mjs
```

- **21/21 项技能函数回归检查通过**（包含〖割圆〗从 13 点到 3 点的连续结算与无效弃牌检查）。
- 已通过 **Google Chrome 真实战局冒烟测试**：进入无尽 3-1，选择 DIY 张春华；发动〖镇魂〗并弃置牌后，三名敌人获得封印状态，且〖割圆〗正确记录弃牌点数。
- 浏览器测试脚本：[`tests/diy_zhangchunhua.chrome.smoke.mjs`](./tests/diy_zhangchunhua.chrome.smoke.mjs)。
- 测试范围、执行记录与**尚未验证的内容**：[`tests/diy_zhangchunhua.report.md`](./tests/diy_zhangchunhua.report.md)。

**注意：** 21 项 Node.js 测试主要是使用模拟游戏对象调用项目的真实技能函数，不能当作所有 19 项技能均已通过完整实战的证明。浏览器冒烟测试也不覆盖长期关卡、全部技能组合与所有异常路径。
