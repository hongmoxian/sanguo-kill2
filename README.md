# 无名杀 · 无尽模式与 DIY 武将改版

> **非官方、个人学习与游玩用途的二次开发项目**。本仓库基于开源项目 [《无名杀》（libccy/noname）](https://github.com/libccy/noname) 进行修改，重点是 **单人无尽闯关、武将养成、DIY 武将技能与运行稳定性**。这不是《三国杀》或《无名杀》官方发布的版本，也不代表上游开发团队。

**本仓库：** [hongmoxian/sanguo-kill2](https://github.com/hongmoxian/sanguo-kill2)

**上游项目：** [libccy/noname](https://github.com/libccy/noname)

## 本分支主要做了什么？

以下是本分支相对所使用的上游代码所做的主要改动；基础游戏引擎、绝大多数既有武将、卡牌、界面与素材均来自原项目及其生态，**不属于本分支的原创成果**。

### 1. 独立的单人「无尽模式」

- 在游戏模式选择界面提供独立的 **无尽模式** 入口，底层复用现有对决模式的战局引擎。
- 新游戏从 **无尽 3-1（1v3）** 开始；大关推进后敌人数量递增，最多 **1v7**。
- 新游戏可从候选池**自由选择 3 名武将**：1 名主将、2 名备用武将；支持大关时切换备用武将，以及主将阵亡后接替。**DIY 武将仅允许玩家选择**：敌方 AI 的初始选将、后续关卡补充、候选池耗尽后的重建以及旧存档读档，均会排除 DIY 武将包成员与 `diy_` 前缀角色。
- 提供最多 **3 次开局换手牌**；进入新大关时提供奖励选择（体力上限与回复、摸牌、护甲、额外出【杀】次数）。
- 记录关卡、已通关数、部分角色状态、备用武将及 DIY 技能选择，支持在重新进入无尽模式时选择继续或开始新游戏。

> **存档限制：** 目前主要保存关卡进度和部分角色数据，并非完整的「任意时刻战局快照」；不能据此保证手牌、当前回合和所有临时技能状态原样恢复。存档保存在浏览器本地环境，清理网站数据或更换浏览器可能导致进度丢失。

### 2. DIY 张春华：技能组合与成长机制

`character/diy/` 中的 `diy_zhangchunhua` 初始体力上限为 **8**，拥有 **20 项可选技能**。进入无尽模式、选择「开始新的无尽游戏」并选完三名武将后，只要主将或备用武将包含 DIY 张春华，就会弹出独立的技能选择窗口：

1. 20 项技能**默认全部勾选**；可逐项勾选，也可使用「全选」「全不选」（允许 0 项）。
2. 技能列表在弹窗内部独立滚动，支持滚轮、触屏和方向键；底部的「确认技能并开始游戏」始终保留在视口内。
3. 确认后仅启用勾选的技能，未选技能不会被角色初始化重新加载；切换备用武将或过关不会重置技能组合。
4. 选择保存在浏览器本地无尽存档的 `diySkills` 字段中，**继续存档不再弹出选择界面**；只有「开始新的无尽游戏」才会重新默认全选。

（兼容旧存档：若旧存档尚无 `diySkills` 字段，读档时按原行为启用全部 20 项；空数组 `[]` 则表示明确关闭所有技能。该存档仍是关卡进度快照，而非实时牌局快照。）

其中重点定制、调整的玩法包括：

- **〖割圆〗**：用实际进入弃牌堆的牌点亮点数圆环；完成后移除两端点数、重建圆环。
- **〖解术〗**：围绕圆环状态提供手牌上限与摸牌等联动。
- **〖股算〗**：与圆环缩减进程关联的觉醒机制。
- **〖杀意〗、〖镇魂〗等**：按照本地玩法调整攻击、弃牌与封印效果。
- **〖完杀〗**：持有者可以使用【桃】，其他角色不能使用【桃】；全局持续生效。
- **〖流转〗**：以刘巴原版技能为基础，在 DIY 张春华的无尽模式中增强为**其他角色回合内获得的牌（包含正常摸牌阶段）均可标记“转”**；你不能成为包含“转”牌的实体牌目标。**其他角色结束回合时，仍留在其手牌里的全部“转”牌必须自动弃置，再由张春华通过流转回收；没有“转”标记的手牌保留。**敌人在其他时机弃置的“转”牌也能回收；敌人阵亡时，其手中带“转”的牌会在死亡弃牌清理前直接交给 DIY 张春华。标记成功及回收时均播放刘巴原版语音。涉及同一张黑色“转”牌时按 **割圆 → 流转 → 落英** 的优先级结算；仅修改无尽模式 DIY 张春华的行为，不改变原版刘巴效果。
- **技能特效（DIY 流转）**：标记“转”时在目标头像附近显示轻微淡紫提示；真正回收转牌时在**画面中央**播放约 1.4 秒的浅紫金色“流转”光环、流光汇聚与回收数量动画，兼容正常弃牌、阵亡和回合结束回收。视觉层不阻塞点击、不显示隐藏牌面、不会改变技能结算；连续回收可合并显示。可访问 `/tests/liuzhuan.vfx.preview.html` 独立预览特效（不影响存档）。
- **技能语音**：〖割圆〗、〖解术〗、〖股算〗复用刘徽原版各两条配音；〖流转〗保留刘巴原版两条配音，四个技能均补齐独立字幕映射。

其余技能中有复用、继承或调整自既有武将技能的部分，例如〖国色〗、〖固政〗、〖惴恐〗等；**20 项技能不代表 20 个均为原创设计**。

### 3. 无尽模式流程和兼容性修复

针对实际游玩和浏览器测试，修复或调整过：

- 无尽模式启动、选将事件排队与技能注册；
- 页面更新后旧 Service Worker / 缓存造成的脚本版本不一致；
- **读档首关敌人数量**：先恢复大关等级，再生成敌人；第 5-12 关为 1v5，第 7-3 关为 1v7，不再固定出现 3 人；
- **AI 敌将多样性**：玩家选将仍展示随机候选，但 AI 使用完整的非 DIY 武将库，当前池全部抽完才重新补池，开局也不再重复初始化敌方座位；
- **长局存档兼容**：旧存档敌方候选池不足 3 人甚至为空时，保留原关卡进度并自动补充候选；
- **误报重置提示**：进入选将或读档交互界面后，解除启动加载计时器，避免正常等待超过 10 秒触发“游戏未正常载入”的弹窗；
- 敌方武将池、换将与其他部分存档恢复逻辑；
- 部分 DIY 技能触发顺序与游戏事件兼容问题；
- 〖割圆〗结算时未定义变量 `litAny` 导致的运行时错误，以及重复触发防护。

这些改动以可用性为目标，但并不意味着所有技能交互、所有存档场景均已完整验证。

## 如何在本地运行

推荐使用较新的 **Google Chrome / Chromium**，通过本地 HTTP 服务打开游戏，不建议直接双击 `index.html` 使用 `file://` 协议。

需要提前安装 [Deno](https://deno.com/)。

在项目根目录执行：

```powershell
cd E:\sanguo-kill
deno task start
```

随后在 Chrome 打开：

**http://localhost:8089/index.html?mode=endless**

首次启动时按页面提示完成初始化及开源协议确认。进入「无尽模式」后选择「开始新的无尽游戏」，从候选武将中选出主将与两位备用武将；如果包含 DIY 张春华，随后选择要启用的技能并确认。已有存档可选择「继续无尽存档」，无需重复选技能。

> 如果你将项目克隆到其他位置，请把上面的 `E:\sanguo-kill` 替换成实际目录。服务器默认使用 8089 端口；本地需允许该端口访问。

## 测试与验证

本仓库提供了针对 DIY 张春华的可重复执行测试：

```powershell
node tests/diy_zhangchunhua.skill.test.mjs
```

- **24/24 项 Node.js 技能函数回归测试通过**，包括〖完杀〗自身使用【桃】、〖流转〗标记/目标限制、〖割圆〗完整循环与异常弃牌检测。
- **Chrome 无尽模式冒烟测试通过**：进入 3-1（1v3）、主将加载 20 项技能、〖镇魂〗弃牌与敌方封印、〖割圆〗点数记录，以及四项技能的语音资源解析。
- **流转端到端测试通过**：敌方摸牌阶段添加“转”标记、标记和回收分别触发语音、弃置后按同一张牌的 `cardid` 完成回收；验证原版刘巴的摸牌阶段规则保持不变。
- **技能选择、存档与 AI 武将池端到端测试通过**：仅开启 3 项技能、角色重新初始化、读档保持组合、开始新游戏恢复默认全选，以及全不选 `[]` 的保存与读档。检查敌方初始阵容、DIY 包成员和 `diy_` 前缀角色的随机抽取过滤、旧存档中混入的 DIY 名单及非法敌将初始化。
- **高关卡读档与重复率回归通过**：第 **5-12 关读档后首关为 5 名敌人**；第 **7-3 关、敌将池为空的旧存档**可恢复并出现 7 名不同敌人。完整候选池超过旧版的 60 人限制，模拟连续抽取 90 名敌将均不重复；停留读档界面超过 10 秒没有触发重置提示。
- 对 **480×360、360×560、1280×720** 三种视口检查了技能列表内部滚动、末项可达和底部确认按钮可见。

Chrome 测试要求：先启动本地服务器（8089），再使用**独立浏览器用户目录**启动支持 Chrome DevTools Protocol 的 Chrome（9252），最后依次运行：

```powershell
node tests/diy_zhangchunhua.chrome.smoke.mjs
node tests/diy_liuzhuan.runtime.test.mjs
node tests/diy_liuzhuan_death_discard.chrome.test.mjs
node tests/diy_liuzhuan_turnend.chrome.test.mjs
node tests/liuzhuan.vfx.chrome.test.mjs
node tests/endless_diy_skill_selection.chrome.test.mjs
```

例如在 Windows 安装 Chrome 的默认路径下，可另开终端执行：

```powershell
& "C:\Program Files\Google\Chrome\Application\chrome.exe" --headless=new --disable-gpu --no-first-run --no-default-browser-check --autoplay-policy=no-user-gesture-required --remote-debugging-port=9252 --user-data-dir="$env:TEMP\noname-cdp-test" about:blank
```

（自动化脚本会在这个**独立测试浏览器目录**中创建新游戏、修改测试存档；不要将 `--user-data-dir` 指向日常游戏的浏览器资料。Node.js 函数测试不等同于所有技能组合的完整长期实战验证。）

历史的技能修复执行记录见 [`tests/diy_zhangchunhua.report.md`](./tests/diy_zhangchunhua.report.md)；其中的 2026-10-25 数据属于历史快照，以本节的最新回归结果为准。
